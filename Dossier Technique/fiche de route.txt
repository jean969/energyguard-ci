--> Étape 1 — Vérifier que Docker Desktop est lancé, puis taper : 
docker run -d --name redis-energyguard -p 6379:6379 redis:7

Docker télécharge et lance Redis 7 automatiquement. Le port 6379 est exposé sur ta machine.

-->> Étape 2 — Vérifier que Redis répond :
docker exec -it redis-energyguard redis-cli ping

 Résultat attendu : PONG — Redis fonctionne parfaitement.


-->> Étape 3 — Relancer Redis après redémarrage de la machine :
docker start redis-energyguard

Le conteneur Redis existe déjà — pas besoin de le recréer, juste le démarrer.
